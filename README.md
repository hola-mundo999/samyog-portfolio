## ✨ Features & Upgrades

- **🌓 Dynamic Dark & Light Theme System:** Smooth top-right toggle with Sun/Moon icons, zero-flash pre-render script, and full persistence across sessions in `localStorage`.
- **📐 UI/UX Design Hierarchy:** Refined spacing (`max-w-5xl`), symmetrical cards, and zero horizontal overflow across all mobile, tablet, and desktop viewports.
- **🚀 Featured Applied Systems:** Showcases 4 interactive systems with live web demos and source code:
  1. *AI CSIT Study & Lecture Notes Assistant* (Python, Streamlit, PyPDF, Gemini/Groq)
  2. *AI Virtual Hand Gesture Controller* (Python, OpenCV, MediaPipe, Streamlit)
  3. *TU CSIT Notice & Routine Alert Hub* (Python, BeautifulSoup4, SQLite3, Telegram Bot API)
  4. *Prime Event & QR Ticket Management System* (FastAPI, Pydantic, QRCode, Tailwind)
- **🏛️ Community Progression & Leadership:** Connected 3-step timeline highlighting tenure with **Prime IT Club**:
  - **Public Relations Advisor** (September 2026 – Present, Current Role)
  - **Public Relations Director** (September 2025 – September 2026)
  - **Public Relations Officer** (July 2024 – September 2025)
- **✉️ Validated Contact System:** Client-side validation (name, email, subject, message) generating formatted `mailto:` links with instant feedback and copy-to-clipboard functionality.
- **🤖 Built-in Portfolio Assistant:** Interactive terminal assistant grounded on verified portfolio facts with keyboard shortcuts (`Escape` dismiss).

## 💻 Local Development Setup

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hola-mundo999/samyog-portfolio.git
   cd samyog-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```

4. **Lint & Code Quality:**
   ```bash
   npm run lint
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
