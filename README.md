# Samyog Sapkota — Developer Portfolio 🌐

A modern, silent 3D developer portfolio showcasing my journey in **BSc CSIT at Prime College**, focusing on **Software Engineering**, **Python**, and **AI/ML**.

Built with **React 19**, **Three.js**, and **Tailwind CSS**.

## 🛠️ Tech Stack

- **Frontend:** [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **3D Graphics:** [Three.js](https://threejs.org/) (Interactive particle constellation & silent wireframe mesh)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Hosting:** [Vercel](https://vercel.com/) / [Cloudflare DNS](https://cloudflare.com/)

## 💻 Local Development Setup

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hola-mundo999/samyog-portfolio.git
   cd samyog-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
